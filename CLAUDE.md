# Project notes for the agent

- This is a Vite + React static site deployed to GitHub Pages by `.github/workflows/deploy.yml` on every push to `main`. It serves at `https://<domain>/<repo-name>/`.
- `package.json` "name" must equal the GitHub repo name. `vite.config.js` derives the `base` path from it.
- `site.config.js` holds the domain, title, description, and OG copy. `scripts/prerender.mjs` reads it at build time and writes the meta tags, JSON-LD, sitemap, and the index-site embed script tags into `dist/index.html`.
- `npm run build` is `vite build` plus the prerender. The deployed HTML contains the rendered page, so `src/main.jsx` uses `hydrateRoot`, and nothing may read `window` during render. Apply URL state in a `useEffect` after mount.
- Shareable state goes in the URL with `replaceState` (`src/urlState.js`). The analytics embed counts each `replaceState` as a pageview.
- Analytics: `window.dhAnalytics?.track(name, props)`, optional-chained because the embed is third-party and blockable.
- Hover interactions use `onPointer*` events, not `onMouse*`, so they work on touch.
- Favicon and OG images are generated by `npm run gen:favicon` and `npm run gen:og` on a developer machine and committed. CI does not regenerate them. Re-run after a redesign.
- Dev server: `npm run dev`. If port 5173 is busy, `npm run dev -- --port 5174`.
- The `dataviz-pages-site` skill covers everything else: build-time data, researched datasets, mobile, dates, SEO, registering the project card on the index site.
- Data is committed; the deploy only builds, so in season a new week lands only when someone runs the refresh. The raw sources live under `data/raw/` (gitignored) and `scripts/fetch-data.mjs` is cached per file, so the whole refresh is: delete `data/raw/cfbfastr/cfb_schedules_2026.csv` and `data/raw/ap-polls/season-2026.html` (the current season's two files; new poll pages download as missing), `node scripts/fetch-data.mjs --only=games` and `--only=polls`, then `node scripts/build-candidates.mjs`, `node scripts/build-records.mjs`, `node scripts/fetch-ot.mjs` (ESPN overtime for the new game ids) and build-records again so `ot.json` reaches `data/records.json` and `src/data/site-data.json`. Check with `node scripts/candidate-stats.mjs` (no seasons flagged) and `node scripts/coverage-report.mjs`; its Kiffin check fails on purpose since he went 1-9. 2026 unmatched games are G5/FCS road teams with no tenure row. A game played after the bulk fetch can be hand-added in `data/game-corrections.json` (`action: "add"`, scored from ESPN) and yields automatically once cfbfastR carries it.
- The og:image is the current-coaches poster (`ogImage` in `site.config.js`), so regenerate it with the data: `npx vite --port 5173` for the logos, `node scripts/gen-poster.mjs > /tmp/poster.html`, render with Chrome (`--headless=new --hide-scrollbars --force-device-scale-factor=2 --window-size=1560,1400 --virtual-time-budget=8000 --screenshot=...`), trim the trailing background rows with sharp keeping ~72px of bottom padding → `public/current-coaches-road-vs-top10.png` (2x), downscale to width 1560 → `public/og-poster.png`, and set `ogImageHeight` in `site.config.js` to the result (1370 as of 2026-10-11). `npm run gen:og` redraws the Kiffin card, which only changes when he plays a road game vs the top 10.
- The intro line (`src/App.jsx`) and the description (`site.config.js`) stay pinned to ESPN's 1-8 factoid, with Kiffin's live number beside it struck through; only his number moves.
